CIROH R2OHC User Support Gets an Upgrade

CIROH's framework for handling user support requests for R2OHC has been made more robust with improved ticketing, allowing us to better support your needs. For support requests regarding CIROH R2OHC Cyberinfrastructure, please email us at ciroh-it-support@ua.edu.

CIROH Hub Publications Mailing List

CIROH Hub now offers weekly and monthly mailing lists with the latest CIROH Publications. To sign up, head to the Publications research portal.

NRDS

ngen-datastream: Now Open to Community Contributions

NRDS now features a full pipeline to integrate community contributions for new or existing datastreams! A new set of contribution documents explains what the NRDS is, what defines a datastream, and the two primary contribution paths: proposing a new datastream or updating an existing one. As of v3.4.0, the contribution pipeline is fully versioned and traceable.

🟢1 day ago👥1 contributor
NRDS

ngen-datastream: On-Premise HPC Deployment

The AWS infrastructure that performs the NRDS simulations has been recreated on Alabama's on-premise HPC NextStream on the infra/lxd branch. This gives the NRDS both a cloud and on premise back-end to deploy datastreams judiciously and efficiently. This release also provides support for t-route restart files, allowing routing simulations to begin with pre-initialized river flows.

NGIAB_data_preprocess

This month's releases enable PET output for NOAH-OWP-Modular, retrieve data faster, and include critical slope calculation and other fixes across all models. Additionally, support for modular configurations is now being tested on the v5.0.0b2 branch, featuring an implementation for the CASAM model and modular ports for all previously-supported realizations.

NRDS

DataStreamCLI

In alignment with ngen-datastream, DataStreamCLI now offers the [https://github.com/CIROH-UA/datastreamcli/issues/new?template=metadata_request.yml](Request Execution Metadata issue form). Users can request metadata output that NRDS currently lacks, shaping the platform's outputs to the community's needs. Additionally, in alignment with NGIAB_data_preprocess, catchment attributes related to hydrofabric slopes have now been fixed.

NRDS

Forcing Processor

In alignment with ngen-datastream, the forcing processor now offers a community contributions form to allow for community input on forcing processing in the NRDS. Additionally, NWM routed flows are now aggregated into the NextGen HydroFabric by maximum, improving NRDS performance against USGS observations
